# 聊天保护（酒馆助手脚本）

防止 SillyTavern 改正则 / 开关正则后聊天被意外清空（例如只剩开场白）。

## 安装
酒馆助手 → 脚本库 → 导入，选择 `酒馆助手脚本-聊天保护.json`，然后打开开关启用。（也可以新建脚本手动粘贴 `chat-guard.js`。） 入口在「扩展」面板里正则设置的下面（「聊天保护」→「聊天快照」）。

## 它会做什么
- **挡下坏保存**：楼层突然骤减（只剩 1 楼、或一次少了 3 楼以上）且不是你手动删楼时，不让这次保存写进文件。
  - 设置「自动恢复」（默认）：挡下后自动把完整聊天重新读回来。
  - 设置「只提示」：只弹小提示，刷新页面即可。
- **手动删楼照常放行**（ST 的删楼、删到这里、酒馆助手的删楼接口都可以）。
- **最新完好版**：每次正常保存后空闲时悄悄更新，压缩存在浏览器 IndexedDB。坏保存永远不会写进来。
- **历史版本**（默认每个聊天 3 份）：只在这些时刻留底——很多楼原文一起被改之前、一次删 3 楼以上之前、每次刷新页面后第一次打开这个聊天时、恢复之前、手动存一份时。
- 如果打开聊天时发现文件已经少了很多楼（例如在别处被写坏），会自动从最新完好版恢复（「只提示」模式下则提示你去面板点恢复）。

## 注意
- 快照存在当前浏览器里，换设备看不到。
- 如果你在别的设备上删过楼，这边可能会误拦一次，在「扩展 → 聊天保护」面板里点「放行」即可。
