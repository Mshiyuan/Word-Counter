# 双击手柄新建条目（酒馆助手脚本）

在 SillyTavern 的预设条目列表里，**双击（手机上是连点两下）条目最前面的「☰」拖动手柄**，就会在这个条目下面新建一个空条目，并自动打开编辑窗口。

- 兼容 [ST-BaiBai-Tools](https://github.com/baibai-git/ST-BaiBai-Tools) 的预设分组：在分组里双击，新条目会进同一个分组；在分组外双击，新条目就不属于任何分组。
- 没装 BaiBai-Tools 也能用。

## 安装

酒馆助手 → 脚本库 → 新建脚本，把 `双击手柄新建条目.js` 的全部内容粘进去，启用即可。

## 可调整的选项

脚本开头的 `CONFIG`：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `newPromptName` | `新条目` | 新条目的名字，重名自动加编号 |
| `openEditor` | `true` | 新建后直接打开编辑窗口 |
| `autoSavePreset` | `true` | 新建后自动保存当前预设 |
| `doubleTapMs` | `350` | 两次点击的最大间隔（毫秒） |
| `moveTolerance` | `10` | 点击时允许的位移（像素），超过就当作拖动 |
