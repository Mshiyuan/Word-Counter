# 酒馆助手脚本

安装：酒馆助手 → 脚本库 → 导入，选择对应的 `酒馆助手脚本-*.json`。

同名的 `.js` 是同一份代码的源码，方便阅读和修改；改完 js 后需要重新生成 json。

两个脚本都兼容 [ST-BaiBai-Tools](https://github.com/baibai-git/ST-BaiBai-Tools) 的预设分组，没装 BaiBai-Tools 也能用。

## 双击手柄新建条目

在预设条目列表里，**双击（手机上是连点两下）条目最前面的「☰」拖动手柄**，就会在这个条目下面新建一个空条目，并打开编辑窗口。

- 在分组里双击，新条目会进同一个分组；在分组外双击，新条目不属于任何分组。
- 默认不自动保存预设，自己手动保存。

脚本开头的 `CONFIG`：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `newPromptName` | `新条目` | 新条目的名字，重名自动加编号 |
| `openEditor` | `true` | 新建后直接打开编辑窗口 |
| `autoSavePreset` | `false` | 新建后自动保存当前预设；默认关闭，需要自己手动保存 |
| `doubleTapMs` | `350` | 两次点击的最大间隔（毫秒） |
| `moveTolerance` | `10` | 点击时允许的位移（像素），超过就当作拖动 |

## 预设新版本迁移条目

导入同一个预设的新版本（比如「XX预设 v1.2」→「XX预设 v1.3」）时，自动弹出对比窗口：

- **旧版独有的条目**：旧版里有、新版里没有的（比如自己缝的条目）。勾选的会放进新预设里和旧版相同的位置——
  放在旧版里它前面那个条目的后面；连着的几条会保持原来的先后顺序；原来关闭的仍然关闭。
- **两边都有、但内容不同的条目**：会写明哪里不同（内容、深度等）。勾选 = 用旧版的内容覆盖新版，适合自己改过作者条目的情况。

判断是不是同一个预设：名字去掉版本号后相同（`v1.2`、`ver2.0`、`3.1.4`、`1025`、`修复版`、`beta` 等都会被忽略），
或者有足够多相同的自定义条目。可以在窗口里换成别的旧预设来对比。

分组：新条目夹在同一个分组中间时会进这个分组；在分组边上时，只有旧版里所在分组和它同名才进。

两种用法：

- **导入时**：合并结果会随导入一起保存（酒馆导入预设本来就会直接保存）。点「跳过，直接导入」就按原样导入。旧预设不会被改动。
- **手动**：点脚本按钮「对比旧版预设」，把当前预设和任意旧预设对比。合并后**不会自动保存**，检查好了再手动保存预设。

脚本开头的 `CONFIG`：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `autoDetectOnImport` | `true` | 导入预设时自动检测旧版本并弹出对比窗口 |
| `minSharedCustomPrompts` | `3` | 名字对不上时，至少要有这么多相同的自定义条目才算同一个预设 |
| `minOverlapRatio` | `0.5` | 名字对不上时，相同自定义条目的占比至少要这么多 |
| `previewChars` | `2000` | 内容预览最多显示多少字 |
