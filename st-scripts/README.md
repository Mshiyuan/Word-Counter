# 预设条目工具（酒馆助手脚本）

安装：酒馆助手 → 脚本库 → 导入 `酒馆助手脚本-预设条目工具.json`。

如果之前装过「双击手柄新建条目」或「预设新版本迁移条目」，请把这两个旧脚本删掉，功能都已经合并到这里了。

`预设条目工具.js` 是同一份代码的源码，方便阅读和修改；改完 js 后需要重新生成 json。

兼容 [ST-BaiBai-Tools](https://github.com/baibai-git/ST-BaiBai-Tools) 的预设分组，没装 BaiBai-Tools 也能用。

## 设置

在酒馆的「扩展」页面里展开「预设条目工具」，可以分别打开 / 关闭：

- 双击条目前的 ☰ 新建条目
- 导入预设时对比旧版本
- 角色条目方案
- 切到没有方案的角色时，恢复预设自己保存的开关

面板里还有「对比旧版预设…」按钮（脚本按钮栏里也有一个）。设置和方案都存在酒馆的扩展设置里（`extension_settings.presetEntryTools`）。

## 双击 ☰ 新建条目

在预设条目列表里，**双击（手机上是连点两下）条目最前面的「☰」拖动手柄**，就会在这个条目下面新建一个空条目，并打开编辑窗口。

- 在分组里双击，新条目会进同一个分组；在分组外双击，新条目不属于任何分组。
- 不会自动保存预设，自己手动保存。

## 导入预设时对比旧版本

导入同一个预设的新版本（比如「XX预设 v1.2」→「XX预设 v1.3」）时，自动弹出对比窗口：

- **旧版独有的条目**：旧版里有、新版里没有的（比如自己缝的条目）。勾选的会放进新预设里和旧版相同的位置——
  放在旧版里它前面那个条目的后面；连着的几条会保持原来的先后顺序；原来关闭的仍然关闭。
- **两边都有、但内容不同的条目**：会写明哪里不同（内容、深度等）。勾选 = 用旧版的内容覆盖新版，适合自己改过作者条目的情况。

判断是不是同一个预设：名字去掉版本号后相同（`v1.2`、`ver2.0`、`3.1.4`、`1025`、`修复版`、`beta` 等都会被忽略），
或者有足够多相同的自定义条目。可以在窗口里换成别的旧预设来对比。

分组：新条目夹在同一个分组中间时会进这个分组；在分组边上时，只有旧版里所在分组和它同名才进。

- **导入时**：合并结果会随导入一起保存（酒馆导入预设本来就会直接保存）。点「跳过，直接导入」就按原样导入。旧预设不会被改动。
- **手动**：点「对比旧版预设…」，把当前预设和任意旧预设对比。合并后**不会自动保存**，检查好了再手动保存预设。

## 角色条目方案

同一个预设，不同角色想开关不同的条目时用。预设面板「提示词」上方会多出一栏：

- **当前角色保存为…**：把现在所有条目的开关（包括 BaiBai 分组的总开关）存成一个方案，给它起个名字。名字和已有方案相同时会问要不要覆盖。
- **下拉框**：选这个角色要用哪个方案，选了马上套用，以后切换到这个角色时自动套用。也能选其他角色存的方案。选「不自动切换」就不管。
- **只对当前聊天存档生效**：勾上后，下拉框选的方案只绑定给这个聊天存档。同一个角色的不同存档可以用不同方案；没单独绑定的存档跟随角色的方案。
- **垃圾桶**：删除选中的方案，用到它的角色和存档都会变成不自动切换。

细节：

- 方案按预设分开保存，换了预设就是另一套方案。预设改名时方案会跟着走。
- 方案只管它保存时就有的条目，之后新加的条目保持原样。
- 切到没有方案的角色时，如果上一个角色套用过方案，会恢复成预设自己保存的开关（还没手动保存的改动不算），免得把上一个角色的开关带过来。不想要可以在设置里关掉。
- 套用方案只改当前的开关，不会自动保存预设文件。

## 脚本开头的 `CONFIG`

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `newPromptName` | `新条目` | 双击新建的条目名字，重名自动加编号 |
| `openEditor` | `true` | 双击新建后直接打开编辑窗口 |
| `autoSavePreset` | `false` | 双击新建后自动保存当前预设 |
| `doubleTapMs` | `350` | 两次点击的最大间隔（毫秒） |
| `moveTolerance` | `10` | 点击时允许的位移（像素），超过就当作拖动 |
| `minSharedCustomPrompts` | `3` | 对比旧版：名字对不上时，至少要有这么多相同的自定义条目才算同一个预设 |
| `minOverlapRatio` | `0.5` | 对比旧版：名字对不上时，相同自定义条目的占比至少要这么多 |
| `previewChars` | `2000` | 对比旧版：内容预览最多显示多少字 |
