# 预设条目工具（酒馆助手脚本）

## 安装与更新

酒馆助手导入脚本时不会覆盖已有脚本：每次导入都会新增一个脚本，并且导入后处于**关闭**状态。因此：

1. 酒馆助手 → 脚本库 → 导入 `酒馆助手脚本-预设条目工具.json`。
2. 删除脚本库中旧版本的「预设条目工具」，以及已合并到本脚本的「双击手柄新建条目」「预设新版本迁移条目」。多个版本同时启用时，实际运行的版本不确定。
3. 启用新导入的脚本。
4. 在「扩展」页面的「预设条目工具」标题中确认版本号。

`预设条目工具.js` 为同一份代码的源码，便于阅读和修改。修改 js 后需重新生成 json。

兼容 [ST-BaiBai-Tools](https://github.com/baibai-git/ST-BaiBai-Tools) 的预设分组。未安装 BaiBai-Tools 时也可使用。

## 设置

位置：「扩展」页面 →「预设条目工具」。

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 预设：双击新建条目 | 开启 | 见「双击新建条目」。 |
| 世界书：双击新建条目 | 开启 | 见「双击新建条目 → 世界书」。 |
| 导入时对比旧版本 | 开启 | 见「版本对比」。 |
| 条目方案 | 开启 | 在「提示词」标题上方显示方案栏。见「条目方案」。 |
| 切换时自动套用方案 | 开启 | 关闭后，切换角色、聊天存档或预设时不修改条目开关，需在方案栏点击「套用」。 |
| 默认值（未记录的条目开关） | 预设上次保存的状态 | 可选「预设上次保存的状态」或「沿用上一个角色的状态」。见「条目方案 → 套用规则」。 |
| 切换时确认未记录的条目 | 开启 | 见「条目方案 → 未记录的条目」。 |
| 排查模式 | 关闭 | 双击时在屏幕上显示识别过程，用于排查双击无反应的问题。 |

面板中的「对比旧版本预设…」按钮用于手动执行版本对比。脚本按钮栏中有同名按钮。

设置与方案保存在 SillyTavern 的扩展设置中（`extension_settings.presetEntryTools`），随 settings.json 保存，与预设文件无关。

## 双击新建条目

双击（触屏为连续点击两次）条目左侧的「☰」拖动手柄，在该条目下方新建一个空条目，并打开编辑窗口。

- 在 BaiBai 分组内双击时，新条目加入同一分组；在分组外双击时，新条目不属于任何分组。
- 不自动保存预设。新条目需手动保存预设后才会写入预设文件。

### 世界书

双击世界书条目左侧的「☰」，在该条目下方新建一个空条目，并展开该条目。

- 仅在世界书排序方式为「自定义」时可用。其他排序方式下 SillyTavern 不显示「☰」。
- 新建后立即保存世界书。所有条目按当前顺序重新编号（`displayIndex`）。
- 编辑器中尚未保存的修改会一并保存，不会丢失。
- 双击的条目是当前页最后一条时，自动翻到下一页显示新条目。

## 版本对比

导入预设时，若已存在名称仅版本号不同的预设（例如已有「XX预设 v1.2」，导入「XX预设 v1.3」），弹出对比窗口。

### 判定为同一预设的条件（满足其一）

- 名称去除版本号后相同。忽略的内容包括 `v1.2`、`ver2.0`、`3.1.4`、`1025` 等数字，以及「修复版」「beta」等版本标记。
- 相同的自定义条目达到一定数量与比例（见 `CONFIG`）。

存在多个旧版本时，默认选择版本号最大的一个。可在窗口中改选其他预设。

### 对比窗口

- **仅存在于旧版本的条目**：例如自行添加的条目。勾选的条目插入新预设中与旧版本相同的位置：
  - 插入到旧版本中位于其前方、且新预设中也存在的最近条目之后；
  - 连续的多个条目保持原有先后顺序；
  - 旧版本中为关闭状态的条目，插入后仍为关闭状态。
- **两个版本中设置不同的条目**：标明差异项（内容、深度等）。勾选的条目以旧版本的设置覆盖新版本。

### 分组

- 插入位置的前后条目属于同一分组时，加入该分组。
- 插入位置在分组边界时，仅当旧版本中所属分组与相邻分组同名才加入。

### 保存

- 导入时执行：所选条目合并到正在导入的预设，随导入一同保存。选择「跳过，直接导入」则按原样导入。旧版本预设不受影响。
- 手动执行：所选条目添加到当前预设，不自动保存预设。

## 条目方案

用于同一预设下，不同角色使用不同的条目开关。

### 方案的内容

方案只记录条目的开关状态，以及 BaiBai 分组的总开关状态。条目本身（是否存在、内容、顺序）属于预设，由所有角色共用：

| 操作 | 影响范围 | 保存方式 |
| --- | --- | --- |
| 新增、删除条目，修改内容或顺序 | 所有角色 | 手动保存预设 |
| 条目开关 | 按方案区分 | 点击「当前角色保存为…」时立即保存，无需保存预设 |

- 方案按预设分别保存。切换到其他预设时，使用该预设下的方案。预设重命名时，方案随之迁移。
- 方案只切换条目开关，不切换所选预设。
- 方案以条目的内部编号识别条目。修改条目名称或内容不影响方案；已删除的条目在方案中被忽略。

### 方案栏

位于预设面板「提示词」标题上方。

- **当前角色保存为…**：将当前所有条目开关保存为方案，并绑定到当前角色（或聊天存档，见下）。名称与本角色已有方案相同时，确认后覆盖。
- **下拉框**：选择当前角色使用的方案，选择后立即套用。可选择其他角色的方案。选择「不使用方案（按默认值）」则解除绑定。
- **仅绑定到当前聊天存档（不勾选则绑定到角色）**：
  - 不勾选：下拉框中的选择绑定到角色，适用于该角色所有未单独绑定的聊天存档。
  - 勾选：下拉框中的选择仅绑定到当前聊天存档。
  - 打开聊天存档时，先使用该存档的绑定；没有单独绑定时，使用角色的绑定。
- **删除按钮**：删除所选方案。使用该方案的角色和聊天存档改为不使用方案，当前开关不变。

### 套用规则

启用「切换时自动套用方案」时，切换角色、聊天存档或预设时自动执行；关闭时，点击方案栏的「套用」按钮执行：

1. 当前预设没有任何方案时，不修改开关。
2. 使用方案时：方案中有记录的条目按方案设置；没有记录的条目按默认值。
3. 未使用方案时：所有条目按默认值。

默认值由设置项「默认值（未记录的条目开关）」决定：

- **预设上次保存的状态**：使用预设文件中保存的开关。未保存的手动修改不计入；尚未保存到预设文件的新条目保持不变。
- **沿用上一个角色的状态**：保持切换前的开关，不作修改。

注意：在某个方案生效时保存预设，该方案的开关会成为预设保存的状态，即其他角色的默认值。仅在新增、删除或修改条目后保存预设即可，切换角色后无需保存。

### 未记录的条目

方案保存后新增的条目，在方案中没有开关记录。启用「切换时确认未记录的条目」时，套用此类方案后弹出窗口：

- 列出未记录的条目，初始勾选状态为默认值。勾选表示开启。
- **写入方案**：勾选结果保存到该方案，之后切换时不再询问。
- **暂不写入**：本次使用默认值，下次切换时再次询问。

未启用时，未记录的条目直接使用默认值。

## `CONFIG`（脚本开头）

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `newPromptName` | `新条目` | 双击新建的条目名称，名称重复时追加编号 |
| `openEditor` | `true` | 双击新建后打开编辑窗口 |
| `autoSavePreset` | `false` | 双击新建后自动保存当前预设 |
| `doubleTapMs` | `350` | 两次点击的最大间隔（毫秒） |
| `moveTolerance` | `10` | 单次点击允许的最大位移（像素），超出视为拖动 |
| `minSharedCustomPrompts` | `3` | 版本对比：名称不匹配时，判定为同一预设所需的最少相同自定义条目数 |
| `minOverlapRatio` | `0.5` | 版本对比：名称不匹配时，判定为同一预设所需的相同自定义条目最低占比 |
| `previewChars` | `2000` | 版本对比：内容预览的最大字数 |
