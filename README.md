# 输入计数（Word-Counter）

作者：时鸢

酒馆助手（Tavern Helper）脚本：在 SillyTavern 输入框右上角显示一个悬浮小标签，**边打字边实时更新** Token 数和字数。不修改酒馆源码。

- **Token**：调用酒馆自己的分词器（`getTokenCountAsync`），跟随当前 API / 模型的分词设置；输入停顿约 0.35 秒后刷新，计算中数字会变淡。拿不到分词器时显示 `≈` 估算值。
- **字数**：汉字、假名、韩文、全角标点各算 1；英文单词 / 数字串各算 1（和 Word 的口径一致）。鼠标悬停可看字符总数。
- 发送后清空、QR 填入文字、切换聊天等程序改动也会跟着刷新。
- 悬浮标签可以**拖动**，位置会记住；双击标签回到默认位置。
- **楼层计数**：每个楼层（包括很早以前的）在头像下方显示 `Token / 字数`，编辑、切换 swipe 后自动重算。开启时会隐藏酒馆自带的楼层 token 显示。

## 安装

1. 酒馆助手 → 脚本库 → 导入，选择 `输入计数.json`，启用即可。（也可以新建脚本，把 `input-counter.js` 的内容粘进去。）
2. 在该脚本的按钮设置里添加名为 **`输入计数`**、**`楼层计数`** 的两个按钮（新版酒馆助手会自动创建）。
3. QR 栏里「输入计数」开关输入框标签，「楼层计数」开关楼层显示，开关状态会记住。

所有设置存于浏览器本地 localStorage，不上传任何服务器。
