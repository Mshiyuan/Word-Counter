# 计字簿（Word-Counter）

作者：时鸢

酒馆助手（Tavern Helper）脚本：在 SillyTavern 输入框右上角显示一个悬浮小标签，**边打字边实时更新** Token 数和字数。不修改酒馆源码。

- **Token**：调用酒馆自己的分词器（`getTokenCountAsync`），跟随当前 API / 模型的分词设置；拿不到分词器时显示 `≈` 估算值。
- **字数**：汉字、假名、韩文、全角标点各算 1；英文单词 / 数字串各算 1（和 Word 的口径一致）。
- **悬浮栏**：点一下收成小球，再点带回弹展开；按住拖动可以移动；**长按打开设置**。
- **楼层计数**：每个楼层显示 `Token · 字数`。被美化挡住时，**长按约 0.4 秒**它会浮起来，拖到想放的位置松手（不长按就是正常滚动，不冲突）。
- **设置**（长按悬浮栏）：
  - 显示方式：「每层独立显示」或「悬浮栏跟随楼层」（显示屏幕上正在看的那一层，输入框有光标时改算输入的文字）。
  - 拖动一层所有楼层跟着变 / 角色和用户分开设置 / 楼层计数回到默认位置。
  - 隐藏酒馆自带楼层计数。
  - 统计口径：是否计入思维链、是否计入隐藏内容（关闭后只算页面上显示的文字），可选角色与用户分别设置。
  - 悬浮栏归位。

## 安装

1. 酒馆助手 → 脚本库 → 导入，选择 `计字簿.json`，启用即可。（也可以新建脚本，把 `input-counter.js` 的内容粘进去。）
2. 在该脚本的按钮设置里添加一个名为 **`计字簿`** 的按钮（新版酒馆助手会自动创建）。
3. 点 QR 栏里的「计字簿」按钮，一键开关输入框标签和楼层计数，开关状态会记住。

所有设置存于浏览器本地 localStorage，不上传任何服务器。
